## [0.17.1] - 2026-11-06

- 配置 docs.rs 全特性构建及真实 documentation 地址，使可选 local_ipc/shared API、最后关闭回调与代理方法进入精确版本在线文档。
- 更新双语 README 的依赖、API 和源码入口，明确仅文档构建启用全部 features，用户默认依赖能力、运行时及协议均不变；保留 0.17.0 标签，发布结果分别核对 registry 与 docs.rs。

## [0.17.0] - 2026-11-06

- 新增 ResourceHandler::close 与 SharedResource::close_with，最后会话的关闭参数和结果随资源协议 v2 传递；异常断连回收引用，关闭/析构错误仍释放所有者配置锁。
- 新增 transact_with_timeout，None 等待实际完成，不新增业务超时；LocalLease 自身的两秒请求截止时间保持不变。
- 资源端点与所有者锁目录升为 miresidian-resource-v2；升级须停止全部 v1 资源代理参与者，配置租约 v2 与 C ABI v7 不变。根框架 0.25.0 接入自动节点所有者，宏标签不变。

- 验证：框架/租约默认 42 项、全特性 157 项通过（1 个子进程辅助入口忽略）；两种真实动态库共享路径、严格 Clippy/Rustdoc、Rust 1.89、Windows x64/x86 编译及版本门禁通过。设备 COM5 与 Windows 原生加载未实测。

## [0.16.0] - 2026-11-05

- 单字段保留旧文本与配置字节，组合编码保留专用前缀并拒绝单值占用；提取资源和参数值对象模块，不改变 IPC 协议或资源所有权。
- 验证：相关角色、编码与兼容回归、默认/全特性工作区、严格 Clippy、Rust 1.89、严格 Rustdoc 和 Release 构建通过；完整范围见根 CHANGELOG 0.24.0。

## [0.15.0] - 2026-11-04

- 新增 `shared::SharedResource` 和 `ResourceHandler`：兼容客户端跨 DLL/进程复用唯一物理资源，工厂只由所有者执行，完整事务按资源串行，最后使用者退出后析构资源。
- 独立资源代理 v1 的有界请求响应、配置/协议匹配、所有者文件锁、模块保活及失败回滚；旧代理在超时、断连或所有者退出后失效，不自动重连或重放。
- LocalLease 的配置协调协议仍为 v2，不改变纯租约对物理句柄的既有含义；Unix 服务也保留实际承载模块。
- 验证：资源级并发、最后关闭、不同进程复用、所有者退出、工厂失败、业务错误/panic 与超时；动态库真实加载使用独占文件模拟硬件。
