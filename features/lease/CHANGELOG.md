- 验证：对应组件与工作区默认/全特性回归、严格 Clippy、Rust 1.89 和 Release 构建通过；完整范围见根 CHANGELOG 0.22.0。

## [0.15.1] - 2026-11-04

- 完善包级接入说明：区分 LocalLease 与 SharedResource，明确运行时 Lease/Direct 选择器不改变通信实现，以及 Windows/Unix 模块保活。
- 补齐中英文 README 与当前 CHANGELOG，示例适配框架 0.20.1；运行时与公开 API 同 0.15.0，配置租约 v2、资源代理 v1 均不变。
- 验证：复用 0.15.0 的资源生命周期及跨 DLL/进程回归；本次校验文档、依赖锁文件与真实 registry 发布包。

## [0.15.0] - 2026-11-04

- 新增 `shared::SharedResource` 和 `ResourceHandler`：兼容客户端跨 DLL/进程复用唯一物理资源，工厂只由所有者执行，完整事务按资源串行，最后使用者退出后析构资源。
- 独立资源代理 v1 的有界请求响应、配置/协议匹配、所有者文件锁、模块保活及失败回滚；旧代理在超时、断连或所有者退出后失效，不自动重连或重放。
- LocalLease 的配置协调协议仍为 v2，不改变纯租约对物理句柄的既有含义；Unix 服务也保留实际承载模块。
- 验证：资源级并发、最后关闭、不同进程复用、所有者退出、工厂失败、业务错误/panic 与超时；动态库真实加载使用独占文件模拟硬件。
