- 精确依赖 codec 0.15.0；实例调度、平台空通道判定及策略默认值不变。
- 验证：对应组件与工作区默认/全特性回归、严格 Clippy、Rust 1.89 和 Release 构建通过；完整范围见根 CHANGELOG 0.22.0。

## [0.16.2] - 2026-11-04

- 精确依赖 codec 0.14.2，使默认候选文本与对应实际值使用一致的配置规范化；实例策略及广播契约不变。
- 验证：默认/全特性工作区回归、严格 Clippy、Rust 1.89、严格 Rustdoc 和 Release 构建通过；与对应框架解析回归一并验证。

## [0.16.1] - 2026-11-03

- 同步 codec 精确依赖至 0.14.1，实例和调度行为不变。

## [0.16.0] - 2026-10-30

- Broadcast 固定只执行通道1并复制结果到有效槽位；通道1无效时不执行、不切换源，不再要求其他输入一致。公开调度语义变化独立升至0.16.0。
- 通用调度5项回归通过；框架默认/全特性52/130项、完整格式/Clippy/MSRV/Release及文档检查通过，原生DLL广播计数验收通过。

## [0.15.0] - 2026-10-30

- 新增公开 plan_multi_channel，供同步和异步前端复用输入跳过、结果位置及广播校验规则。
- 通用同步 Parallel 分发最多 32 个工作线程，按输入位置收集结果并等待全部已开始任务结束。
- Config/Handle 关联及实例数量策略保持；框架原生异步调度使用共享输入计划。

## [0.14.0] - 2026-10-30

- 新增独立实例策略、容器及可选多通道调度；当前已发布版本。
- 此组件独立管理语义版本，只在实际变化时升版及单独发布；历史统一列车编号不构成联动要求。
