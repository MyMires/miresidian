# Changelog

## [Unreleased]

## [0.13.0] - 2026-11-11

- 内嵌执行器先探测 ABI：v7-v9 采用旧三参数签名，v10 组装完整 JSON 调用单参数 miresidian_invoke；其他 ABI 调用前拒绝。
- v10 请求固定 platform=0 使用 DLL 默认平台，响应复制和输入缓冲区释放保持；生成器/指导同步，不宣称已执行 Windows 原生加载。

## [0.12.0] - 2026-11-01

- 增加 --help、--version 和 --check；生成 BAT 前检查 JSON 字符串参数、Delay 范围及基本配置/初始化顺序。
- 继续独立生成自包含 BAT，与统一入口通过进程协作；保留原流程路径用法。
- serde_json 复用工作区已有依赖进行真实 JSON 解析，避免手写转义规则；具体方法及默认值仍在加载 DLL 后核对。
- 验证：JSON/Delay/生命周期单元测试与 BAT 生成通过；原生 Windows 执行交由 CI。补齐 CloseAllDevices 的无配置调用与清理跟踪。

## [0.11.0] - 2026-10-30

- 独立待发布版本：执行脚本支持稳定 code 诊断，保留旧 DLL 缺少 code 的兼容处理。
- 此组件独立管理语义版本，只在实际变化时升版及单独发布；历史统一列车编号不构成联动要求。
