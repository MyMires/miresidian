# Changelog

## [0.1.0] - 2026-11-01

- 首个独立 CLI 版本，提供 cargo miresidian 与 cargo mires 两个等价入口，通过进程调用原工具。
- 清单集中登记工具版本及命令路由；保留标准流、当前目录、含空格参数和后端退出码。
- 提供 Linux/Windows x64 完整套件构建、摘要清单、在线/本地安装及 Shell/PowerShell 包装。
- CLI 与套件从 0.1.0 起步，不使用框架版本；不自动安装后端、不执行远程发布。
- 验证：真实子进程的双入口、参数/目录/退出码和旧工具诊断通过；完整套件安装后新建、编译、检查与 BAT 生成通过，安装器覆盖摘要损坏、ZIP、路径及宿主拒绝。
