# Changelog

## [0.2.2] - 2026-11-01

- 套件清单同步 Pack 0.12.1，统一入口要求该后端版本，使 new 创建的项目包含 AGENTS.md；CLI/套件独立补丁升版，TestFlow 保持 0.12.0。
- 不改变命令参数与安装管理方式；验证限定为工具清单/路由相关单元测试、格式及版本门禁。

## [0.2.1] - 2026-11-01

- Windows 版本替换回归使用独立构建目录，模拟 Cargo registry 安装的构建隔离，避免测试共用同名可执行文件缓存。
- Cargo 安装、升级及版本切换接口不变；独立补丁版本保留 0.2.0 已有标签，不改写旧提交。


## [0.2.0] - 2026-11-01

- 新增 install/update/use/list，通过 Cargo 安装、升级、切换各独立后端版本并保留原生安装记录；支持 --full、各工具版本及常规 Cargo 参数。
- 所有工具默认安装到 Cargo 用户目录；CLI 本体由原生 cargo install 更新，同一根目录每个工具只保留当前版本。
- 删除 Python 用户安装器及 Shell/PowerShell 包装；保留开发构建脚本，验证流程改为真实 Cargo 安装。
- 发行清单登记工具别名，新增后端自动纳入 --full；批次发布先后端后 CLI，不发布无关框架 crate。
- 验证包含真实 Cargo 安装、降级、再升级和记录检查，含空格参数、双入口、退出码及错误参数验证。
- 本地验证：格式、默认/全特性 Clippy 与工作区测试、19 项版本门禁回归、registry 模板、真实 Cargo 安装与版本替换、Rust 1.89、Release 和 Rustdoc 通过；原生 Windows 验证由 CI 执行。

## [0.1.0] - 2026-11-01

- 首个独立 CLI 版本，提供 cargo miresidian 与 cargo mires 两个等价入口，通过进程调用原工具。
- 清单集中登记工具版本及命令路由；保留标准流、当前目录、含空格参数和后端退出码。
- 提供 Linux/Windows x64 完整套件构建、摘要清单、在线/本地安装及 Shell/PowerShell 包装。
- CLI 与套件从 0.1.0 起步，不使用框架版本；不自动安装后端、不执行远程发布。
- 验证：真实子进程的双入口、参数/目录/退出码和旧工具诊断通过；完整套件安装后新建、编译、检查与 BAT 生成通过，安装器覆盖摘要损坏、ZIP、路径及宿主拒绝。
