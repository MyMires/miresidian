# Changelog

## [Unreleased]

## [0.16.0] - 2026-10-30

- Broadcast 固定只执行通道1并复制结果到有效槽位；通道1无效时不执行、不切换源，不再要求其他输入一致。公开调度语义变化独立升至0.16.0。
- 通用调度5项回归通过；框架默认/全特性52/130项、完整格式/Clippy/MSRV/Release及文档检查通过，原生DLL广播计数验收通过。

## [0.15.0] - 2026-10-30

- 新增公开 plan_multi_channel，供同步和异步前端复用输入跳过、结果位置及广播校验规则。
- 通用同步 Parallel 分发最多 32 个工作线程，按输入位置收集结果并等待全部已开始任务结束。
- Config/Handle 关联及实例数量策略保持；框架原生异步调度使用共享输入计划。

## [0.14.0] - 2026-10-30

- 新增独立实例策略、容器及可选多通道调度；当前已发布版本。
- 此组件独立管理语义版本，只在实际变化时升版及单独发布；历史统一列车编号不构成联动要求。
