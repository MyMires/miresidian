# 宏驱动开发

Miresidian 的驱动公开契约由方法签名和可选标注声明，驱动作者不得手写 `GetFunctions`、`GetInitConfig`、操作字符串分发或 C ABI 入口。`#[miresidian::node_impl]` 在编译期读取这些信息并生成对应内容。

## 声明方式

```rust
#[miresidian::node("示例设备")]
#[derive(Default)]
pub struct ExampleDriver {
    // 驱动状态与通信对象。
}

#[miresidian::node_impl]
impl ExampleDriver {
    fn init_device(
        &mut self, address: String, port: u16,
    ) -> DriverResult<String> {
        # let _ = (address, port);
        # Ok("已连接".to_owned())
    }

    fn close_device(&mut self) -> DriverResult<()> {
        Ok(())
    }

    #[miresidian::operation]
    fn query(
        &mut self,
        request: String,
        maximum_bytes: usize,
    ) -> DriverResult<String> {
        # let _ = (request, maximum_bytes);
        # Ok(String::new())
    }
}
```

`node` 的参数为 DLL 的平台展示名称。`node_impl` 识别以下约定方法：

| Rust 方法 | 平台操作 | 标注规则 |
| --- | --- | --- |
| `init_device` | `InitDevice` | 每个非 `self` 参数自动成为 Config；`config` 仅用于覆盖名称或默认值。 |
| `close_device` | `CloseDevice` | 参数自动成为 Input；通常没有参数。 |
| `get_port_no` | `GetPortNO` | 可选；参数自动成为 Input，且无需先初始化。 |
| 任意方法 | 自动 PascalCase 或标注名称 | 使用 `operation` 标记；每个参数自动成为 Input。`input` 与 `output` 仅用于覆盖自动名称或增加默认值。 |

宏自动生成固定的 `GetFunctions` 与 `GetInitConfig`，以及每个驱动 DLL 的 `miresidian_invoke_v1`、`miresidian_free_output_v1`、`miresidian_last_error_v1` 和 `miresidian_abi_version` 导出函数。稳定 Rust 不允许把属性直接写在 `->` 后的返回类型上，因此 `output` 放在方法上、紧邻 `operation`。

未带字符串的 `operation` 会把 Rust 方法名转换为测试平台的 PascalCase：`read_text` 变为 `ReadText`，`read_tcp_ip` 变为 `ReadTcpIp`。`init_device`、`close_device` 与 `get_port_no` 是固定平台入口，分别固定映射为 `InitDevice`、`CloseDevice`、`GetPortNO`；其中 `GetPortNO` 是唯一的缩写特例。

未使用 `config` 或 `input` 标注时，平台参数名同样自动转为 PascalCase，例如 `port_name` 为 `PortName`、`port_no` 为 `PortNo`。缺少 `output` 标注且返回类型不是 `DriverResult<()>` 时，宏使用“返回值”作为单个输出名；`DriverResult<()>` 自动生成空输出。

## 可跨语言使用的类型

输入和输出 ABI 都是 UTF-8 文本。宏目前支持 `String`、`bool`、常用有符号/无符号整数、浮点数、`Option<T>` 和 `Vec<T>`。数组在平台侧使用 `|` 分隔，例如 `1|2|3`。`Vec<T>` 输出为一个 `|` 分隔的输出值；二元和三元元组可映射为多个输出值。

配置或输入标注中的 `名称:默认值` 会同时生成平台元数据，并用于缺失或空白参数的默认值解析。调用方仍可传裸值或 `名称:值`。
