## 共享调用槽位对齐

共享调用按已创建通道的当前顺序定位：第 N 个输入槽位对应第 N 个通道。输入槽位数不得超过已创建通道数；响应严格保持输入槽位的顺序和数量，不为未提供输入的后续通道补空输出。

例如已创建 A、B 两个通道，输入槽位 `[["one"]]` 只调用 A，并返回一个槽位 `[A 的输出]`；输入槽位 `[["one"], ["two"]]` 依次调用 A、B，并返回两个同序槽位。空白或不合法输入仍占用其位置，并在该位置返回空输出。

## 并行共享调度

`Parallel` 按实际有效输入槽位数创建并发任务：一个有效输入对应一个通道调用；跳过槽位不创建线程。当前设备规模下不设置额外并发上限，输入、输出及错误中的通道序号始终以请求槽位顺序为准。`Sequential` 与 `Broadcast` 的既有顺序语义保持不变。
