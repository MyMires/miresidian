# Miresidian 0.23.0：配置规范文本与转义选项映射

## 中文

实例配置比较与租约参数编码共用按初始化 Config 原 Rust 类型生成的归一化回调。数值空白、0、等价进制形式形成相同规范文本，不再发生业务得到零、实例或租约却按不同原字符串判冲突的情况。类型别名直接通过 trait 分派，不按类型名称字符串猜测。

新增 DeviceInput::normalize_device_text 和 DeviceNode::normalize_config_value。前者默认保留原文，内置数值、bool、格式、Option/Vec 提供相应规范形式；后者由节点宏按初始化参数生成。自定义类型可覆盖纯归一化逻辑，不取得资源或执行设备动作，不要求新增 DeviceOutput 实现。String 保留文本，Option 保留 None 与 Some(0) 区别，普通 Vec 的空集合不变。

初始化主键/Handle 判空仍先于类型解析，不能将空身份补成零对象。多实例业务调用和关闭仍按主键/Handle 定位，非主键字段不替换对象保存的配置，也不因无关字段的非法类型文本阻断正确目标的路由；单实例按完整规范配置定位。

选项显示值映射复用集合的转义识别，匹配完整元素后重新转义；字面竖线后半段不再被当成独立显示值。例如候选 `A-甲/B-乙` 下，数组输入 `prefix\|乙` 得到一个元素 `prefix|乙`，不会变成 `prefix|B`。非法集合转义仍由目标类型报错，普通 String 保留实际文本。

节点声明约束由完整 Node skill 与当前手册共同维护：路径、开放文本默认位留空，不写示例路径或候选项，由用户输入；连续数值默认/预填位留空，科学计数法只作为实际输入。路径声明使用 `文件路径:`，倍率声明使用 `倍率:`；框架不新增路径类型、猜测或转义语法，也不将完整候选文本取首项。有限离散选项与框架策略默认值继续按真实契约声明。

迁移时将同一资源的通信提供者和节点采用的规范配置编码对齐。内置数值会从原字面形式转换为规范文本；旧 DLL 的非规范编码不保证与新版本兼容，应在关闭旧会话后统一升级并重建。资源键、字段名/顺序及协议仍须由各项目约定。

组件版本：框架 0.23.0、codec 0.16.0、宏 0.21.0、format 0.3.2、batch 0.2.2、instances 0.16.4、lease 0.15.3。工具版本不变。C ABI v7、配置租约 v2、资源代理 v1、MSRV 1.89 不变。源码提交及标签不代表 registry 发布；独立节点只采用已发布精确版本，禁止本地覆盖。

## English

Generated configuration normalization now uses the original Rust parameter type for both instance comparison and lease encoding. Numeric blanks, zero and equivalent radix representations share canonical text. Type aliases use trait dispatch. Blank Config/Handle identities still skip initialization before normalization, and nonkey fields do not change multi-instance routing.

DeviceInput::normalize_device_text preserves text by default and supports custom pure normalization. Built-in numbers, booleans, formats, optional values and vectors provide their own canonical forms. Generated DeviceNode::normalize_config_value bridges this behavior to the runtime and lease requests without requiring custom input types to implement DeviceOutput.

Option mapping recognizes escaped collection boundaries before matching complete labels. A literal pipe no longer exposes the remaining fragment to an unrelated label replacement. Existing array escaping, invalid-escape checks and empty collection semantics remain available.

Node guidance requires empty default fields for paths, open text and continuous numeric parameters. Paths have no default, candidates or dropdown; users supply the actual value. Scientific notation remains valid input but is excluded from default/candidate declarations. No new path type or path escape grammar is introduced.

Align canonical configuration encoding across providers sharing one resource, and close old sessions before upgrading noncanonical encodings. C ABI v7, lease v2, resource v1, Rust 1.89 and tool versions remain unchanged. Publication remains separate from source commits and tags.
