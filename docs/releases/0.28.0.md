# 0.28.0：feature 宏简写

[文档中心](../README.md) · [节点手册](../宏驱动开发.md) · [实例管理](../instances.md)

## 范围与发行状态

根框架源码 0.28.0、miresidian_macro 0.24.0；本次只形成源码提交和本地不可移动标签，未推送或发布 crates.io，也不声称新版本 docs.rs 已可访问。安装示例仍选用已经核实的发行；独立 Node 不得通过 path/git 覆盖采用本候选。C ABI 保持 v9、ABI crate 0.16.0，租约/资源代理协议保持 v2，MSRV 1.89；其他组件和工具版本不变。

## 新旧语法对照

| 原声明 | 新声明 |
| --- | --- |
| instances(mode = single, execution = sequential) | instances 或 instances() |
| instances(mode = single, execution = parallel) | instances(parallel) |
| instances(mode = multiple, binding = config, execution = sequential) | instances(multiple, config) |
| instances(mode = multiple, binding = handle, execution = sequential) | instances(multiple, handle) |
| instances(mode = multiple, binding = handle, execution = selectable, default_execution = sequential) | instances(multiple, handle, selectable(sequential)) |
| lease(activation = required) | lease 或 lease(required) |
| lease(activation = disabled) | lease(disabled) |
| lease(activation = selectable) | lease(selectable(required)) |
| format(formats = [hex]) | format(hex) |
| format(formats = [utf8, hex, base64], selector = "数据格式") | format(utf8, hex, base64, selector = "数据格式") |

完整可编译的内存回显示例见 [macro_shortcuts.rs](../../examples/macro_shortcuts.rs)，需开启 instances、lease、format、batch 四项 feature。宏的简称不自动启用 Cargo feature。

## 默认与平台契约

- 不写 instances：保持默认单对象、不接受多通道。写裸 instances：启用单对象、固定 sequential 多通道。新位置参数省略模式默认 single，省略策略默认固定 sequential；multiple 仍须明确 config/handle。单对象调用仍互斥；多通道请求仍只定位一个对象。
- 裸 lease：固定 Required，不增加访问方式 Config；不写 lease 仍为 Direct。selectable(required) 才发布 Lease/Direct 选择器并默认租约；本次不新增 selectable(disabled) 默认直连。参数 lease(key/ignore)、完整初始化一致性、共享节点和最后引用关闭规则不变。
- format 直接列格式，支持六种既有标识符 ascii/gbk/utf8/utf16le/hex/base64。单格式无选择器，多格式必须 selector 且首项默认；输入选择器跟随数据，输出选择器追加方法 Input 末尾。selector 的名称和选项顺序不应在等价迁移中改写。
- batch 仍独立，原参数类型、范围与转义、记录广播/对齐、顺序、首错停止及输出聚合不变；同样支持 sync/async 和逐条格式列。

## 兼容与错误

旧完整声明继续支持；无需修改旧节点。旧 NameValue 实例声明的必填项、租约旧 resource/configuration 配对列表、格式具名参数的合法次序均保留原规则。单个 feature 分组不混合长短语法；不重复声明 feature、实例模式/关联/策略或编码；裸 selectable、缺失默认策略、multiple 缺关联、single 带关联、多格式缺 selector、固定格式带 selector 均报编译错误。租约旧字段列表仍不能和参数角色混用。

未提供 format/lease 等号别名、集中 Input 名称列表、operation 输出合并或自动标记 impl。方法和参数继续逐项标记。ABI 入口、响应字段/稳定错误码、调用返回文本所有权、运行时和租约线协议均未修改。

## English

Source candidate: framework 0.28.0 and macro 0.24.0. No registry publication, push, or new docs.rs availability is claimed. ABI v9, protocols v2 and Rust 1.89 remain unchanged.

Feature shorthand normalizes to existing policies and codecs. Bare instances enables single-object sequential multi-channel execution, while omitting it still disables multi-channel requests. Multiple mode requires config/handle. Bare lease equals required; selectable(required) keeps Lease as the selectable default. Format accepts positional encodings, with an explicit selector for multiple choices and the first encoding as default. Input/Output layout, batch alignment, async support and resource cleanup remain equivalent to long declarations.

All existing long forms remain valid, including legacy resource/configuration lists and named format-option ordering. Do not mix long and short syntax within a group or declare duplicate policies/encodings. Cargo features remain explicit. Existing nodes need no migration, and independent nodes must wait for publication instead of using local framework overrides.
