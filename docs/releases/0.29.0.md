# 0.29.0 公开类型命名迁移

本页对应尚未发布的源码候选；Git 提交、本地标签、crates.io 发布和 docs.rs 文档是分别核实的状态。独立节点须待所需框架及组件正式发布后选择精确依赖，不使用 path/git/patch 本地覆盖。

## Rust 接口

框架面向通用节点、外部资源与业务调用。本次移除公开类型中的设备限定，不保留旧名称别名：

| 旧名称 | 新名称 | 定义组件 |
| --- | --- | --- |
| DeviceInput | NodeInput | codec 0.17.0 |
| DeviceOutput | NodeOutput | codec 0.17.0 |
| DeviceCollectionElement | NodeCollectionElement | codec 0.17.0 |
| DeviceScalar | NodeScalar | codec 0.17.0 |
| DeviceValue | NodeValue | codec 0.17.0 |
| DeviceNode | Node | 根框架 0.29.0 |

编解码 trait 方法同步更名：

| 旧方法 | 新方法 |
| --- | --- |
| parse_device_text | parse_text |
| normalize_device_text | normalize_text |
| into_device_output | into_output |
| parse_device_collection | parse_collection |
| format_device_collection | format_collection |

更新 import、自定义 trait 实现、显式 trait 调用和泛型约束；基础类型、一维集合、Option、元组和显式格式转换的既有行为保持。自定义输入实现示例见 [codec README](../../codec/README.md#通用节点类型0170-源码)。

`Node` 继续由 node/operation 宏生成，节点作者不手写实现。如果业务结构体本身也叫 Node，可用 `use miresidian::Node as _;` 仅将 trait 方法引入作用域，或在泛型约束中使用 `miresidian::Node` 完整路径。

## 版本与边界

- 根框架 0.29.0、codec 0.17.0、macro 0.25.0、format 0.4.0、batch 0.3.0 为本次 Rust 源码接口迁移候选；精确依赖和工作区锁文件同步。
- instances 0.16.7、lease 0.17.2 只更新现有 codec 精确依赖，不改变实例/租约/共享资源 API 或协议。
- Pack 0.13.4 使生成指导不再硬编码某个版本的节点 trait 名；CLI/套件 0.3.4 同步 Pack 最低版本。现有 new/init 模板仍仅接受已发布 ABI v7，不能据此直接新建本候选版本项目。
- C ABI v9、配置租约/资源代理协议 v2、JSON、内存所有权、状态与错误文本、平台固定操作名保持。Rust 生命周期 init_device/close_device 仍与既有平台入口映射，本次未改名。
- 自定义枚举仍通过 NodeInput 解析；本次不包含从枚举自动生成平台候选的新功能。
- 已发布旧版资料与历史归档保留旧名称。独立节点和烟测夹具继续使用其实际已发布依赖，不在本次修改。

实施和验证记录见[方案](../../plans/2026-11-11-device-naming-audit.md)。本地构建及测试不能替代 Windows 宿主或真实硬件验收。
