# Miresidian 0.22.0：参数契约与审核修复

## 中文

业务 Config/Input 的描述原样发布，但不再推导运行时默认值或将完整候选文本转换为首项。缺参报错；显式数值空白为整数 0 或浮点 0.0，非空非法值、越界和非有限值报错；具体选项显示值仍映射为实际值。

| 0.21.x 调用 | 0.22.0 迁移 |
| --- | --- |
| `超时:1000` 缺参或传空，期待补 1000 | 显式传 `1000`；空白现在为 0，缺参报错 |
| 直接传 `9600/19200`，期待得到 9600 | 传具体 `9600` 或 `19200`；数值不接受完整候选文本 |
| `备注:` 标注后省略 Option 参数 | 显式传空字符串得到 None；缺参报错 |
| 省略初始化的非主键 Config 或普通 Input | 传入所有业务参数；Handle 前的业务位置保持完整 |
| 以路径描述作为默认路径 | 通过普通 String 传实际路径；不补路径、不改写分隔符 |

描述 `超时:1000` 不变。若平台根据描述填入 1000 再传给框架，1000 是有效实际输入。框架不校验每个数值零是否符合设备需求，业务节点仍须在副作用之前校验允许范围。String 保留实际文本，普通 Vec 的空集合语义和数组/batch 转义不变；batch 数值空记录按单值得到零。TB 空通道判定仍先于类型解析。Config[0]/Handle 初始化空身份仍跳过，不能因零值规则创建对象。

format 格式选择器、执行策略及租约访问策略的显式框架默认值保留。低层 codec helper 的显式 default 参数继续可用，业务宏不再从描述生成该参数；手写 Rust 契约迁移时应明确评估其自行指定的默认值。

其他修复：GBK 禁用 BOM 编码探测与替换，非法 GBK 返回 INVALID_ARGUMENT；format 所有编码拒绝 NaN/正负无穷标量、数组及 Option 输出；Handle 在未创建或关闭最后对象后统一 UNKNOWN_CHANNEL；Pack 来源门禁覆盖 batch/format，并核对框架组件集合。

组件：框架 0.22.0、宏 0.20.0、codec 0.15.0、format 0.3.1、batch 0.2.1、instances 0.16.3、lease 0.15.2、Pack 0.13.1、CLI/套件 0.3.1。ABI crate 0.14.0、C ABI v7、配置租约 v2、资源代理 v1、TestFlow 0.12.0 和 Rust MSRV 1.89 不变。源码提交不等于 crates.io 发布；独立节点须在所需版本已发布后升级精确依赖并重建，禁止本地覆盖。

## English

Business parameter descriptions remain unchanged on the platform, but no longer supply runtime defaults or select the first item from a complete choices string. Missing arguments fail. Explicit blank numeric values become zero; malformed, out-of-range, and nonfinite values fail. Concrete display labels still map to actual option values.

Pass every business argument explicitly, including values before Handle. Send `1000` to request that timeout; an empty string now means zero. Send a concrete baud rate rather than `9600/19200`. An optional argument needs an explicit blank value for None. Paths remain ordinary strings, without defaults, separator conversion, or new escape syntax. Arrays retain their existing escaping and empty-collection behavior. Platform channel skipping and blank instance identities are evaluated before numeric parsing.

Explicit framework defaults for format selectors, execution and lease policies remain available. The low-level codec helpers retain their explicit default argument; generated business parameters no longer derive it from descriptions.

GBK decoding disables BOM detection and replacement. Formatted float outputs reject NaN and infinities across scalars, vectors and optional wrappers. Missing Handle lookups consistently return UNKNOWN_CHANNEL even when the instance store is empty. Pack validates all framework crates, including batch and format, using a packaged component inventory checked against the workspace.

C ABI v7, lease protocol v2, resource protocol v1 and Rust 1.89 remain unchanged. Registry publication is a separate action; independent nodes must adopt published exact versions without local overrides.
