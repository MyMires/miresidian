# 0.25.1：完整共享租约 API 文档与正式发布准备

组件：框架 0.25.1、lease 0.17.1；宏保持 0.22.0，其他 crate/工具、C ABI v7、配置租约 v2、资源代理 v2、MSRV 1.89 不变。

本补丁修复 lease 缺少 docs.rs 可选功能构建配置的问题，启用在线文档的全部 features，确保 SharedResource、ResourceHandler、close_with、transact_with_timeout 和 local_ipc 可查；用户依赖仍需显式启用 local-ipc 或根 lease feature，默认能力不变。根同步精确依赖和双语资料入口，无运行时代码或宏标签变化。

自动 Lease 继续将同资源、同命名契约及完整初始化参数的引用指向唯一节点对象，状态共用，最后关闭才释放资源与租约。Direct 保持本地独占。独立业务状态或不同节点类型共用连接仍使用通信层 SharedResource。迁移前停止资源代理 v1 参与者；旧 DLL 必须升级到已发布依赖后重编。

按[本次发布计划](../../plans/2026-11-06-publish-node-leases.md)先发布 lease 0.17.1，再发布根 0.25.1；保留 0.25.0/0.17.0 原标签，不补发中间候选。registry、Git 源码及 docs.rs 分别核实，未生成文档时使用同版本源码入口，不将上传成功当作文档成功。独立 Node、工具和恒惠 DLL 不在本次升级范围。

验证复用 0.25.0 的默认 42 项、全特性 157 项、两条动态库路径、Clippy、MSRV 与 Windows 编译证据；本补丁针对文档配置生成严格全特性 Rustdoc并核对具体 API 页，正式 cargo publish 保留 registry 包编译验证。现场 COM5 和 Windows 原生加载没有新增实测。

## English

Framework 0.25.1 tracks lease 0.17.1 with all-feature docs.rs builds for optional shared-resource APIs. Runtime code, macro syntax/version, default features, other components, C ABI v7, configuration lease v2, resource protocol v2, and MSRV are unchanged. Automatic Lease shares the node owner and its state; Direct remains local. Independent business objects share connections through the communication provider.

Publish lease before the framework, retain original tags, and verify registry availability, package/source provenance, and exact-version documentation separately. Reuse existing runtime validation and perform targeted strict Rustdoc plus Cargo's formal registry package verification. No device test or independent Node/tool upgrade is included. Actual publication outcomes are recorded in the release plan.
