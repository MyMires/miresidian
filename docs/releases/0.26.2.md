# Miresidian 0.26.2：文档分类与去重

日期：2026-11-08。根框架文档补丁候选，尚未发布。

文档入口按阅读任务分类，每个主题由一份手册负责；其他页面通过链接关联。参数声明、实例身份、对象生命周期、共享连接和维护规则的归属见[文档中心](../README.md#核心文档与专题)。历史复盘与旧版本叙述移入[维护历史](../history/maintenance.md)，未实现需求集中于[后续演进计划](../architecture.md#后续演进计划)。

本次新增的参数声明要求由[节点开发手册](../宏驱动开发.md#首个业务-config-的默认值)定义，skill 只保留资料查询及验收入口，并同步完整安装副本。运行时行为、宏编译检查及独立 Node 均未改变。

仅根框架由 0.26.1 升至 0.26.2；其他 crate、工具、内部精确依赖、C ABI v8、配置租约/资源代理 v2 和 MSRV 1.89 保持原状。安装示例不使用本次未发布候选；本任务不推送或发布。

实施与文档/skill/版本检查证据见[任务方案](../../plans/2026-11-08-first-config-default.md)。未新增运行时构建、Windows 加载或硬件验证。

## English

This unpublished root documentation patch classifies guides by responsibility and replaces duplicate rules with links. Retrospectives and old version narratives move to the maintenance archive; unimplemented requests move to the roadmap. The node guide owns parameter authoring requirements, while the skill retains lookup and review entry points. Runtime behavior, other component versions, ABI/protocols and independent nodes remain unchanged.
