# 0.30.0 枚举候选与唯一 JSON 调用入口

本页描述未发布源码候选。提交、本地标签、registry 发布及 docs.rs 可访问资料分别核实；独立节点须待依赖发布后再迁移，不使用 path/git/patch 本地覆盖。

## NodeEnum 使用方式

```rust,ignore
#[derive(miresidian::NodeEnum)]
enum ReceiveMode { IdleTimeout, Terminator, Length }

#[miresidian::input("接收方式")]
mode: ReceiveMode,
```

派生生成 NodeInput、NodeOutput、NodeCollectionElement 和结构化 EnumOption 候选；无需手写转换、重复候选表或改变模块布局。成员名是实际值，数字 discriminant 不参与；仅支持非空、无泛型、无字段枚举。派生不要求 Clone/Copy/Default；batch 本身仍要求 Clone。

参数没有非空冒号后缀时使用候选。TB 生成 `接收方式:IdleTimeout/Terminator/Length`；手写 `接收方式:IdleTimeout-空闲超时/Terminator-结束符/Length-固定长度` 时原样保留，并由 TB 先将具体显示值规范化，再交给枚举 codec。缺参、未知值或完整候选文本不自动取首项。Option/Vec 转发候选，空白规则保持。

具体候选格式和对应输入转换属于同一个实际平台适配器的 format_parameter / normalize_parameter；其他平台可使用 JSON 等表示。未实现枚举支持的平台明确返回 NOT_SUPPORTED，不套用 TB 格式。无枚举的旧自定义 codec/适配器仍沿用原路径，format 参数不额外要求 NodeInput。

手写 ParameterDescriptor 需新增 enum_options 字段，普通类型设 &[]；宏会从参数的 NodeInput::OPTIONS 自动填充。原始 definition/signature 查询不选择平台；发布给宿主使用 *_for 入口。直接 Rust NodeRuntime::invoke_with 接受 &dyn PlatformAdapter，普通引用调用不变，旧显式 turbofish 调用需移除。

## ABI v9 到 v10

v10 唯一业务调用入口是：

```c
uint32_t miresidian_abi_version(void);
const char *miresidian_invoke(const char *request_json);
```

旧三参数 miresidian_invoke、四参数 miresidian_invoke_with 和旧名称 miresidian_invoke_request 均移除，不保留兼容导出。宿主必须先读取版本确认 10，再绑定单参数函数指针；v7-v9 的同名导出有不同签名，不能复用旧函数指针。

请求示例：

```json
{"platform":1,"function":"GetFunctions","config":[],"input":[]}
```

function 必填非空，config/input 缺省 []，platform 为可选 u32 JSON 整数。拒绝 null、错误类型、重复/未知字段和非对象请求。JSON 响应、稳定状态分类、指针归属及立即复制要求保持；同线程下次业务调用会替换响应缓存，版本查询不会。

### 调用时指定平台

- platform 非零指定已注册平台；0 或省略（MIRESIDIAN_PLATFORM_DEFAULT）使用 DLL 固定默认平台，不再沿用之前显式自定义平台。
- GetFunctions/GetInitConfig 不包含“平台适配”Config。旧调用应删去该项，后续共享执行方式向前移动；同一新布局用于默认和显式请求。
- 存活实例期间不允许切换平台。显式自定义平台初始化后，每次调用继续传该平台编号；省略/0 的默认平台若不同会报冲突。关闭全部对象后可重新指定。
- 删除 MIRESIDIAN_PLATFORM_RUNTIME_SELECT 和用于旧平台选择器的 selector_definition、*_with_platform 描述 helper、PLATFORM_ADAPTER_DEFINITION。平台编号 1 和自定义起点 65536 保持，0 是调用路由值而非具体适配器。
