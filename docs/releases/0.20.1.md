# Miresidian 0.20.1 / miresidian_lease 0.15.1

## 中文

本次交付跨 DLL/进程共享资源能力及完善后的 Node skill、调用文档和示例。配置租约与物理连接共享分别管理：LocalLease 校验资源配置，SharedResource 让不同业务对象共用一个连接，并对完整收发事务互斥。

- 同一 DLL 的同 Config/Handle 复用保持原有身份规则；不同 Handle、DLL 和节点类型保留独立业务状态。
- 通信提供者须统一物理资源键、配置编码和事务协议，在工厂内部打开设备；最后代理退出后关闭连接。
- 框架 Lease/Direct 选择器只控制运行时配置租约，不自动切换通信实现；现有节点须接入代理并重建 DLL。
- 已有对象不能在复用时改变 Lease/Direct；关闭后重新初始化。已提交请求超时或断连不自动重连或重放，设备动作可能仍在执行。
- 框架 0.20.1 与 lease 0.15.1 相对上一源码候选仅完善文档；运行时和公开 API 对应 0.20.0/0.15.0。C ABI v7、配置租约 v2、资源代理 v1 不变，其余 crate、工具和独立节点不跟随升版。

验证复用前一候选的 127 项相关全特性通过、1 项既有忽略及 23 项默认特性通过结果；独占文件和动态库实际加载覆盖改名 DLL、独立节点状态与最后关闭，Windows x64/x86 已做编译检查。严格 Clippy、Rust 1.89 与严格 Rustdoc 通过。本次新增文档、skill、示例与发布包校验。模拟证据不等于真实串口或 Windows 宿主通信通过。

接入见[共享资源提供者与可运行示例](../shared-resources.md)、[Node skill](../../skills/miresidian-node/SKILL.md)及[实例身份](../instances.md)。独立节点使用已发布精确版本，不采用本地依赖覆盖。

## English

This release delivers cross-DLL/process resource sharing with the completed Node skill, call documentation, and examples. Configuration leases and shared physical connections have distinct responsibilities: `LocalLease` validates configuration, while `SharedResource` keeps one connection and serializes complete transactions for independent business objects.

- Config/Handle reuse within one DLL retains its existing identity rules. Different Handles, DLLs, and node types keep independent business state.
- Providers must agree on physical resource identity, configuration encoding, and a versioned transaction protocol. Open the device inside the factory; close it after the last proxy exits.
- The runtime Lease/Direct selector controls runtime configuration leases only. Existing nodes need provider integration and rebuilding.
- Reuse rejects Lease/Direct changes. Close before reinitializing. Sent-request timeouts and disconnects do not trigger automatic reconnect or replay; submitted device actions may still be running.
- Version 0.20.1/0.15.1 completes documentation over the preceding 0.20.0/0.15.0 source candidates. Runtime APIs are unchanged. C ABI v7, configuration leases v2, and resource proxies v1 remain unchanged; unrelated crates, tools, and independent nodes keep their versions.

Validation reuses 127 related all-feature tests passed with one existing ignored test and 23 selected default-feature tests passed. Exclusive-file/native-library simulations cover renamed libraries, independent node state, serialized transactions, and last close. Windows x64/x86 compilation checks, strict Clippy, Rust 1.89, and strict Rustdoc passed. This release additionally validates documentation, skill contents, the runnable example, and registry packages. These simulations do not establish real serial communication or Windows host loading.

See the [provider contract and runnable example](../shared-resources.md), [Node skill](../../skills/miresidian-node/SKILL.md), and [instance identity rules](../instances.md). Independent nodes must use published exact versions without local dependency overrides.
