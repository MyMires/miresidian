# 0.33.0：实例能力名称统一为 instance

本页对应未发布源码候选：框架 0.33.0、macro 0.29.0、miresidian_instance 0.17.0。源码版本、Git 标签、crates.io 发行和 docs.rs 文档是不同状态；本任务仅完成源码及本地版本提交，不执行推送或发布。

## 名称映射与迁移

| 旧名称 | 新名称 |
| --- | --- |
| Cargo feature `instances` | `instance` |
| 节点宏 `instances` / `instances(...)` | `instance` / `instance(...)` |
| crate / Rust 导入 `miresidian_instances` | `miresidian_instance` |
| 源码目录 `features/instances/` | `features/instance/` |
| `NodeDescriptor.instances` | `NodeDescriptor.instance` |
| 宏生成的 `__require_instances_runtime` | `__require_instance_runtime` |

旧 feature 和节点宏入口不保留别名，升级时一并替换。长写仍使用 `mode/binding/execution/default_execution`，短写仍使用 `single/multiple/config/handle` 及执行策略。初始化参数上的 `instance(key/ignore)` 无需修改；它与节点级实例策略通过标注位置区分。

以下仅为发布后的依赖目标形态，候选未发布时不能直接安装。独立节点必须先核对 crates.io 的框架与新包发行以及精确版本 docs.rs；不得以 path/git/patch 绕过。通常只需依赖根框架：

```toml
# 迁移目标示意；候选未发布时不可安装。
[dependencies]
miresidian = { version = "=0.33.0", features = ["instance"] }
```

直接使用通用实例容器的项目，发布后将依赖键和导入路径改为 `miresidian_instance`，精确版本采用 `=0.17.0`；需要调度时保留该包的 `runtime` feature。新包不能沿用旧包的 0.16.x 安装说明。

```rust,ignore
#[miresidian::node("设备", instance(multiple, config))]
struct ExampleNode;
// 参数级主键角色保持：#[miresidian::config("设备地址", instance(key))]

use miresidian_instance::{InstanceMode, InstancePolicy};
```

本仓库当前 serial、tcp_client 和独立 smoke-node 仍依赖先前已发布版本，保留旧写法及锁文件；只有主动采用新发行时才迁移并提升各自版本。历史发布记录和标签保持旧版本事实。

## 行为与工具边界

本次统一名称及策略错误 field，不改变默认单实例、Config/Handle 身份、复用/清理、锁、租约、顺序/并行/广播调度或 C ABI v10。未声明节点标记时仍禁用多通道，仅开启 Cargo feature 不自动创建多个对象。

Pack 0.13.5 将新包纳入框架来源检查，并保留旧 `miresidian_instances` 的相同约束；CLI/套件 0.3.6 同步最低 Pack 版本。batch 0.3.2 仅同步组合指导。其他组件及协议无需跟随升版；工具模板仍按自身支持的 ABI 使用。

## English

Framework 0.33.0 and macro 0.29.0 rename the Cargo feature and node group from `instances` to `instance`, without compatibility aliases. The package/import becomes `miresidian_instance` 0.17.0 under `features/instance`; the public descriptor field becomes `NodeDescriptor.instance`. Parameter-level `instance(key/ignore)` stays unchanged. Lifecycle, policies and ABI v10 are unchanged.

These are unpublished source candidates. Independent nodes must wait for verified crates.io releases and exact-version documentation before upgrading. Pack 0.13.5 validates both current and legacy package names; CLI/toolset 0.3.6 requires that Pack version. Existing published dependencies and historical release records retain their original names.
