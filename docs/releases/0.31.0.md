# 0.31.0 枚举成员显示值

根框架 0.31.0 配套 macro 0.27.0，在 `#[derive(miresidian::NodeEnum)]` 处理的无字段枚举成员上支持两种等价标注：

```rust,ignore
#[derive(miresidian::NodeEnum)]
enum State {
    #[node_enum(display = "空闲")]
    Idle,
    #[node_enum("运行中")]
    Running,
    Unknown,
}
```

参数只需 `#[miresidian::input("状态")]`，TB 自动候选为 `状态:Idle-空闲/Running-运行中/Unknown`。其他平台通过 EnumOption.value/display 生成自己的格式，配套把显示输入转换为实际值。直接 Rust codec 只解析实际成员名，业务输出仍为 Idle/Running/Unknown；不把显示值改成输出值或运行时默认值。Option/Vec、Config、初始化/探测/业务 Input、batch 和多通道沿用同一元数据及既有平台转换链。

每个成员可有一个非空白显示字符串，允许单个末尾逗号。长短写不能在同一个成员重复或混用；未知键、非字符串、多余参数和枚举级标注在编译期拒绝。显示文字原文保留，TB 分隔符、首尾空白及跨成员歧义仍由 TB 适配器检查，不施加给其他平台。

未标注成员、手写非空参数描述、成员顺序、cfg/cfg_attr、数字 discriminant 处理、实际值及错误边界保持。已有代码无需修改；使用新标注的项目应先确认所选框架已正式发布，再以 crates.io 精确依赖升级，不能将本地候选作为独立 Node 的 path/git 覆盖。

仅根与宏增加新公开能力并提升次版本；codec、C ABI v10、配置租约/资源代理 v2、MSRV 1.89 和开发工具保持。本次仅本地源码交付，尚未发布，不宣称新版本的 registry 或 docs.rs 已可用。实际验收记录见[方案追加任务](../../plans/2026-11-11-enum-display-options.md)。

## English

Framework 0.31.0 and macro 0.27.0 add equivalent `#[node_enum(display = "label")]` and `#[node_enum("label")]` annotations on fieldless enum members. Omitted labels default to member names. Each member accepts one nonblank string and an optional trailing comma; duplicate, mixed, unknown-key, wrong-type, extra-argument and enum-level annotations fail to compile.

Only structured display metadata changes. Platforms render choices and normalize display inputs; direct Rust codecs and outputs retain member names. Existing explicit descriptions take precedence. Platform syntax and ambiguity checks remain in each adapter. Existing code needs no migration. New annotations require an actually published framework before upgrading independent Node projects through exact crates.io dependencies. These are unpublished local source candidates; ABI v10, lease/resource protocols v2, MSRV and other components are unchanged.
