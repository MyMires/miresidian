# Miresidian 0.21.0：类型驱动的 batch 与独立 format

## 中文

本版本移除普通 batch 的数值类型白名单。原方法参数为 String、bool、char、数值或实现相应 codec 契约的类型时，可以直接标注 batch；类型别名和完整路径按同一 trait 处理。

- 整数保留单值、列表、非负递增范围和混合 `1-3|5|8-10`；浮点/布尔不推断范围，字符串的 `1-3` 保持文本。
- batch 负责记录与调用，format 负责单条表示转换，两个 crate 互不依赖。宏组合数据列和格式列，单值广播、其他等长。
- 原参数为 String 时，`A|42|Qw==` 与 `UTF8|HEX|Base64` 依次得到 A、B、C。batch 输出格式选择器也可按记录提供。
- 固定 `format(formats = [hex])` 不需要 selector，不增加输入槽位。String batch 只传 `41|42` 即得到 A、B；不组合 batch 时同样支持固定编码。
- 输入解析、格式和长度校验先于业务执行；保持顺序、业务/输出失败停止、已有副作用不回滚及逐槽输出。编码记录的解码结果不会再次被当成范围或列表。

组件版本为框架 0.21.0、宏 0.19.0、batch 0.2.0、format 0.3.0。codec、lease、instances、开发工具及 C ABI v7 不变。此文件描述源码版本；独立节点仍须确认 registry 已发布后才能升级精确依赖。

见 [batch](../../features/batch/README.md)、[format](../../features/format/README.md) 和 [Node skill](../../skills/miresidian-node/SKILL.md)。

## English

Plain batch parsing now follows the original Rust argument's codec traits rather than a numeric-name whitelist. Strings, booleans, characters, numeric types, aliases, and compatible custom elements can use batch directly.

- Preserve integer single values, lists, nonnegative ascending ranges, and mixed `1-3|5|8-10` syntax. Floats and booleans do not infer ranges; strings retain range-like text.
- Batch owns record alignment and repeated calls; format owns single-value conversion. The implementation crates remain independent and are combined by generated macro code.
- Data and format columns support singleton broadcast and equal-length pairing. String data `A|42|Qw==` with `UTF8|HEX|Base64` produces A, B, C. Batch output format selectors also support per-record formats.
- Fixed single-format annotations create no selector or extra input slot. A HEX String batch accepts `41|42` and produces A, B. Fixed formats also work without batch.
- Complete input conversion and alignment before business execution. Preserve sequential calls, stop-on-error, no rollback, output-slot grouping, and sync/native async behavior. Decoded records are not recursively interpreted as list/range syntax.

Affected versions: root 0.21.0, macro 0.19.0, batch 0.2.0, format 0.3.0. Unrelated components and C ABI v7 are unchanged. Registry publication remains separate; independent nodes must use published exact versions without local overrides.
