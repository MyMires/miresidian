# Miresidian 0.24.1

## 中文

本次为指导性资料与文档构建配置补丁，运行时 API、C ABI v7、配置租约 v2、资源代理 v1 和各框架内部依赖版本不变。

- [固定入口](../宏驱动开发.md#固定入口的实现与失败边界) 明确初始化、关闭和可选发现的职责、签名、返回与失败清理；[平台结果](../c-abi.md#固定查询与发现结果) 明确 GetPortNO 的找到、未找到及错误。
- 实例手册与 Node 模板消除强制 Config[0] 主键的旧说明。实际身份按项目依赖版本的声明和元数据判断，0.24.0 的组合身份规则不变。
- docs.rs 全特性构建覆盖公开 format API；[资料导航](../README.md#按实际版本查阅) 提供精确版本、发布提交及旧版组件文档回退，已发布旧包不覆盖。
- 工具说明分清源码与可安装版本，提供 [Windows GNU 手动配置](../coding-standards.md#windows-gnu-目标的手动配置)。工具安装不自动配置系统链接器，也不代替目标宿主加载验证。
- [文档同步门禁](../versioning.md#指导性文档与版本同步门禁) 要求指导内容随对应组件更新；skill 保持独立的开发流程和查询规则，不跟随组件升版修改。

源码版本：框架 0.24.1、Pack 0.13.2、CLI/套件 0.3.2。工具各自独立发布，安装前查询 registry；源码提交、标签和 docs.rs 配置不表示在线发行已完成。已有节点继续使用各自已发布依赖，无需为文档修复强制升级。

## English

This patch corrects development guidance and documentation build configuration. Runtime APIs, C ABI v7, lease v2, resource protocol v1 and internal framework dependency versions are unchanged.

Lifecycle and discovery documentation now covers signatures, resource cleanup, and found/not-found/error results. Instance guidance and generated templates no longer impose Config[0] as the identity. The 0.24.0 composite identity contract is unchanged.

The docs.rs build enables all features to expose the public format API. Version-aware navigation explains how to find exact release sources and older component documentation. Tool instructions distinguish source versions from installable releases and link to manual Windows GNU setup.

The version gate requires component READMEs and relevant framework guides to accompany version changes. The Node skill remains independent of framework and tool releases.

Source versions are runtime 0.24.1, Pack 0.13.2 and CLI/toolset 0.3.2. Registry publication and online documentation availability must be verified separately. Existing published packages and tags are immutable; existing nodes retain their selected published dependencies.
