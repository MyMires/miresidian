# 0.30.1 交付资料补齐

本补丁只修正文档及 Rustdoc，不改变 NodeEnum、平台转换、唯一 JSON 调用或 ABI v10 行为。

- 编码规范不再复制过期的 ABI 入口/版本表，统一引用实际版本的 C ABI 契约。
- 元数据注释区分原始声明与平台渲染结果；历史平台名称只用于拒绝旧 Config 和诊断，不会生成平台选择器。
- ABI 公共源码说明采用通用业务节点和资源语义；状态码、头文件和协议编号保持。
- 根框架 0.30.1、ABI crate 0.17.1，精确依赖与锁文件同步；其他组件不升版。0.30.0 的功能和不兼容迁移见[原发行说明](0.30.0.md)。

Node skill 保持版本无关，按实际依赖查阅官方技术资料，不复制具体宏/API 或固定 ABI 表。仓库和安装副本的全部 5 文件逐字节一致，本次没有修改 skill。

验收仅为源码注释与运行时代码无变化核对、两组件严格 Rustdoc、格式/本地链接/版本门禁；复用 0.30.0 的已通过行为验证，不重跑整套构建、测试或硬件检查。未推送、未发布。记录见[任务方案](../../plans/2026-11-11-enum-display-options.md)。
