## 新入口

```c
const char *miresidian_invoke_request(const char *request_json);
```

```json
{"function":"GetFunctions","config":[],"input":[]}
```

function 必填非空；config/input 省略为 []，提供时只能是有序字符串数组。platform 可省略，沿用 miresidian_invoke 的初始化 Config 平台选择；提供时必须是 u32 JSON 整数，沿用 miresidian_invoke_with 且初始化 Config 不携带平台选择器。1 为内置 TB，2..65535 当前保留，第三方从 65536 起且须已注册。拒绝 null、重复/未知字段、类型错误和非对象，平台错误与具体数值范围见 [完整契约](../c-abi.md#完整请求入口v8)。

## 迁移与内存

两个旧调用导出及其签名、响应保持。升级的 DLL 报告 ABI 8，原先恰等于 7 的宿主检查应在评估后增加 v8 支持，不能假定任意更高 ABI 都兼容。旧 DLL 不自动增加新符号，使用新入口前确认支持版本及符号可用性。node 宏自动生成入口，业务方法和标注无须更改。

三个入口共用运行时、实例和线程响应缓存。输入由调用方持有，保证调用期间可读和 NUL 终止。响应字段仍为 status/code/message/output，DLL 持有返回指针，调用方立即复制且不得修改/释放；同线程下一次任一调用入口、线程退出或 DLL 卸载使旧指针失效。ABI 版本查询不替换缓存。

验证结果与未验证范围记入 [实施方案](../../plans/2026-11-06-unified-abi-request.md)。本任务不宣称 Windows 加载、真实设备或候选在线文档可用。

## English

Add `miresidian_invoke_request(const char *request_json)` in C ABI v8. The object has a required nonempty function, optional ordered string arrays config/input (default []), and optional u32 numeric platform. Omission preserves Config-based platform selection; presence preserves explicit selection and excludes the initialization platform selector. Reject null, unknown/duplicate fields, malformed types, and non-object requests. Existing calls and responses remain available; all three entries share runtime state and thread-local response ownership. Copy responses before another call and never free them. Hosts accepting exactly v7 need a reviewed v8 compatibility update before loading a rebuilt DLL. Source candidates and local tags do not imply registry publication or online documentation availability.

当前 Pack 0.13.2 的 `new/init` 模板流程明确只接受 ABI v7，不能用它创建目标 ABI v8 的节点；本任务未升级或验证该模板流程。既有节点在候选发布后手动升级时须按新头文件更新交付说明。TestFlow 保留原同步入口调用方式，不能因此推断其已采用完整请求入口。
