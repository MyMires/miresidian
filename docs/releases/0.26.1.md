# Miresidian 0.26.1：中文注释与文档勘误

本检出为未发布的指导修复：框架 0.26.1、macro 0.23.1、ABI crate 0.15.1、instances 0.16.6、Pack 0.13.3、CLI/套件 0.3.3。仅实际受影响组件补丁升级；其余组件、可执行代码、Rust/C 签名、C ABI v8、配置租约 v2、资源代理 v2 与 MSRV 1.89 保持不变。

## 注释与指导修复

- 根运行时、过程宏及工作区示例统一中文说明，补充宏条件编译与属性展开顺序、初始化输出失败回滚、任务结果容量、协作取消和模块加载引用约束；保留标准 Safety 标记及 API 专名。
- 业务描述默认值与候选首项解析的迁移起点纠正为 0.22.0；0.23.0 的类型规范化另行引用。
- 架构图区分 Direct 本地 N 与 SharedNode 代理，展示唯一所有者持有共享 N，更新八个库/三个工具及 format、batch、CLI 关系。
- 组件 README 明确本检出与已核实发行的安装示例，Pack 文档分别说明 new/init 的目录要求。

## 已发布版本与本次候选

框架 0.26.0、macro 0.23.0、ABI 0.15.0 已在后续授权阶段正式发布；原文中的“不发布”是原实现阶段记录，不能继续作为当前发行结论。旧 CHANGELOG、发行包和标签保留，本次补充勘误及当前指导。[发布执行结果](../../plans/2026-11-06-unified-abi-request.md#发布执行结果)包含来源、checksum 和精确文档验收。

2026-11-07 复核根 0.26.0、ABI 0.15.0、instances 0.16.5 和根 0.25.2 均已发行且未撤回。安装示例采用这些明确的发行版本，后续选择其他版本时仍需查询各自 registry 记录。本次 0.26.1 等补丁没有推送或发布，不能在外部节点用 path/git/patch 覆盖代替发行。

## 工具兼容边界

Pack 0.13.2 及本次 0.13.3 源码的 new/init 模板只接受 ABI v7，本次没有增加 v8 模板能力。CLI 示例显式传 `--miresidian-version 0.25.2`；自动查询选到 v8 时会先写模板再报未完成，不能当作项目初始化成功。new 要求目标不存在；init 要求目录存在并拒绝覆盖模板目标。详情见 [Pack](../../tools/miresidian-pack/README.md#最小模板) 与 [CLI](../../tools/miresidian-cli/README.md)。

本次 CLI/套件 0.3.3 内嵌 Pack 最低版本 0.13.3；TestFlow 仍为 0.12.0。现有 v8 项目按实际头文件手动维护依赖和交付说明，再验证编译及加载。独立 Node、烟测夹具的 registry 依赖和锁文件不因本次指导修复升级。

## 验证与适用范围

实际检查及结果记录于[实施方案](../../plans/2026-11-07-comments-and-documentation.md)。验证重点为源码注释外 token 不变、版本/锁文件一致、严格 Rustdoc、文档链接/锚点、示例编译和工具清单/路由。既有运行时回归只在相同行为与依赖适用范围内复用；本次不宣称新 Windows DLL 加载或真实硬件验证。
