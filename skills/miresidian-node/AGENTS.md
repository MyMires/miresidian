# Miresidian Node skill 维护规则

本文件只约束此 skill 自身的维护，不是 Node 业务项目的开发步骤。

- 框架仓库中的完整副本为 `skills/miresidian-node/`；已安装副本通常为 `${CODEX_HOME:-$HOME/.codex}/skills/miresidian-node/`，以实际安装位置为准。仓库副本受 Git 管理，安装副本供 AI 使用。
- 每次修改任一副本，都应在同次任务中同步另一份全部文件，包括新增、修改和明确删除的文件；不要用旧副本覆盖本次已确认的新内容。开始同步前检查另一份是否有未合并改动，存在时先合并，不能直接覆盖。
- 根据会话工作区或已知检出位置找到框架，不在可分发的 skill 中写死某台机器的绝对路径。另一份确实无法访问时，保留当前修改并明确报告尚未同步的位置，不声称已完成同步。
- 主文档保持 Node 项目事项为主线；安装、命令参数和环境排查放入工具子文档。新增引用文档时同步维护主文档入口。
- 同步后核对两份的相对文件清单和文件内容一致，并进行 skill 格式、内部引用和元数据检查。纯文档同步不重跑框架、工具或全部平台的编译测试。
- 不把缓存、临时校验依赖和构建产物带入任一副本。框架中的提交与版本影响遵守仓库规则；不因 skill 规范变更升级无关产品版本。
