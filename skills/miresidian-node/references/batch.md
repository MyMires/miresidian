# batch：按类型顺序批量调用

选择 batch 时读取。适配版本见 [主文档](../SKILL.md#适配版本)；共用配置见 [能力依赖](node-development.md#能力依赖)。batch 组织记录和重复调用，format 只处理单条表示转换，两者独立启用。

## 依赖与标注

```toml
[dependencies]
miresidian = { version = "=0.24.0", features = ["batch"] }
```

在普通 operation 的 Input 上标记，原方法仍接收单条记录。字符串、布尔无需 format：

```rust
#[miresidian::operation("设置")]
fn set(
    &mut self,
    #[miresidian::input("名称", batch)] name: String,
    #[miresidian::input("开关", batch)] enabled: bool,
    #[miresidian::input("序号", batch)] index: u16,
) -> MiresidianResult<()> {
    self.device.set(name, enabled, index)
}
```

输入 `["A|B|C", "true", "1-2|4"]` 依次调用 `(A,true,1)`、`(B,true,2)`、`(C,true,4)`。方法类型及其 codec 决定输入语法，宏不按类型名称白名单判断；类型别名与完整路径遵循同一 trait 实现。

## 类型与记录语法

| 原方法参数类型 | batch 接受形式 |
| --- | --- |
| 整数 | 单项 `1`、列表 `1|3|5`、范围 `1-5`、混合 `1-3|5|8-10`；范围沿用非负递增边界，负整数可作单项/列表 |
| f32/f64 | 单项、列表、负值和科学计数法；拒绝范围，不推断步长 |
| String | 单个字符串或转义竖线列表；`1-3` 是一个字符串，不展开 |
| bool | 单值或列表；沿用 true/false、1/0、是/否、真/假的元素解析，不支持范围 |
| char | 单字符或字符列表，每项必须是一个字符 |
| 自定义类型 | 普通 batch 须有 DeviceInput、DeviceCollectionElement 和 Clone，实现自身解析规则；不自动臆造嵌套集合协议 |

外层使用 `|` 分隔记录，字面竖线和反斜杠写作 `\|`、`\\`。空文本是一条空记录，由目标类型校验：String 可得到空字符串，数值为零，bool 空白报错；业务描述不提供运行时默认值，缺参报错。普通 Vec 的空集合规则不因此改变。

## 展开与执行

- 整数混合示例 `1-3|5|8-10` 展开为 `1,2,3,5,8,9,10`。最长记录列决定调用次数；长度一广播，其余必须等长，按位置配对，不做笛卡尔积。
- 只标记普通业务 Input，不用于 Config、初始化、关闭或探测。未标记 Input 按实际输入值复用。
- 批量输入解析、格式选择和长度校验先于业务调用。执行固定顺序，首个业务错误或输出转换错误停止；已有副作用不回滚，各输出槽位按调用顺序聚合为可逆竖线集合。
- 组合 [instances](instances.md) 时先定位一个对象，再执行各记录；batch 不展开 Config 主键/Handle，不等于多通道或并行。

## 与 format 组合

需要表示转换时同时启用 `["batch", "format"]`，按 [format 记录与选择器](format.md#与-batch-组合) 组织数据及格式。每条编码记录先选格式，再解码为原方法类型的一条值；解码出的竖线不再次拆分，编码记录不会被重新解释成整数范围。

数据列和格式列各自允许单值或列表，长度一广播、其他等长。输出格式选择器在 batch 方法中也可以按记录提供；没有 batch 的 format 仍只接受一个格式。固定单编码没有选择器，不增加“输入类型”参数。

## 验收

覆盖整数单项/列表/范围/混合、浮点、字符串、布尔、别名、转义和空记录；验证单值广播、等长/不等长、缺参错误和数值空白、未标记参数复用、顺序、首错停止及逐槽聚合。组合 format 时增加不同记录编码、数据广播、格式广播、固定单编码无选择器、输出格式及同步/async；选择或解析失败不得执行业务。
