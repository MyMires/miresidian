# Changelog

## [Unreleased]

## [0.16.0] - 2026-11-02

- 新增 `#[miresidian::input("名称", batch)]` 参数级标记：普通业务方法可保持单个基础整数参数与单值逻辑，由生成包装层解析 `1|3|5`、`1-5` 等数组输入，按位置广播、顺序调用并聚合结果。
- `batch` 不适用于初始化、关闭、常驻探测或 Config 参数；未启用根 crate 的同名 feature 时，带标记的节点在编译期失败。

## [0.15.0] - 2026-10-30

- operation 支持 async 方法，生成 Send Future 业务桥和同步兼容桥；初始化、关闭和探测支持 async 生命周期桥。
- DLL 同步入口共享 OnceLock<NodeRuntime>，完整业务调用不再持有外层 Mutex。
- 配置、命名、默认值、编解码和返回文本契约保持；未新增 C ABI 入口。
- 验证包含宏编译诊断、原生 async 方法、默认/全特性与实际动态库加载。

## [0.14.0] - 2026-10-30

- instances 声明、构造预校验和节点契约生成；当前已发布版本。
- 此组件独立管理语义版本，只在实际变化时升版及单独发布；历史统一列车编号不构成联动要求。
