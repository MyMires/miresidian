# Changelog

## [Unreleased]

## [0.23.1] - 2026-11-07

- 用中文补全 node/operation 的生成职责、模块别名绑定、cfg 传播、依赖重命名及 output 属性展开顺序；不改变生成的可执行代码或宏标注。
- README 区分 0.23.0 已完成的发布与本次源码修订，并说明 Pack 的 v7 模板限制。验证记录见根方案。
- 验证：3 项宏单元、根 doctest、六个根示例编译及严格 Rustdoc 通过；非注释源码与前版一致。

## [0.23.0] - 2026-11-06

- node 自动生成 `miresidian_invoke_request`，委托框架统一解析请求，三个入口共用同一 OnceLock 运行时。
- 保留旧导出与标注方式；新增导出的 Safety/返回指针说明，README 同步完整请求入口及发布边界。
- 依赖根框架 0.26.0 提供的请求运行时 API，生成链与共享状态由集成和动态库烟测验证；候选不自动发布。

## [0.22.0] - 2026-11-05

- 解析初始化 Config 的嵌套 instance(key/ignore)、lease(key/ignore)，分别生成实例键索引与租约字段元数据。
- 编译期拒绝重复/冲突/未知角色、错误参数来源与实例模式、缺失资源键及新旧租约声明混用；保留既有 Config 描述和旧租约声明。
- 验证：相关角色、编码与兼容回归、默认/全特性工作区、严格 Clippy、Rust 1.89、严格 Rustdoc 和 Release 构建通过；完整范围见根 CHANGELOG 0.24.0。

## [0.21.0] - 2026-11-05

- 按初始化 Config 的原 Rust 类型生成归一化回调，实例配置及租约编码共用；不按字段名称或类型字符串猜测。
- 验证：相关定向回归、默认/全特性工作区、严格 Clippy、Rust 1.89、文档及 Release 构建通过；完整范围见根 CHANGELOG 0.23.0。

## [0.20.0] - 2026-11-05

- 业务 Config/Input 的冒号后缀仅作为平台描述，不再推导运行时默认值；描述及显示值映射保持，真实缺参报错。
- 保留 format 选择器等框架生成的显式默认值；初始化、业务、探测、关闭和 batch 使用相同参数规则。
- 验证：对应组件与工作区默认/全特性回归、严格 Clippy、Rust 1.89 和 Release 构建通过；完整范围见根 CHANGELOG 0.22.0。

## [0.19.0] - 2026-11-05

- 移除普通 batch 的基础数值名称白名单，生成代码按原方法类型调用集合解析，支持字符串、布尔、字符、别名与相应自定义类型。
- 宏组合独立的 batch/format API，对数据和格式列分别广播/对齐；batch 方法的输出格式也可逐条选择。固定单编码不生成选择器，格式单独使用仍为单值。
- 保留参数来源、输入槽位、整数混合、顺序/失败语义和同步/async 桥接；格式选择及批量输入校验先于业务执行。

## [0.18.0] - 2026-11-03

- 增强标注由 codec(...) 改为 format(...)，生成包装引用 miresidian::format；旧 codec 标注在编译期拒绝，默认 codec 解析调用保持不变。


## [0.17.0] - 2026-11-03

- 新增输入/输出 codec 标签、合成格式输入、逐槽位输出和同步/async 转换包装。
- batch 支持全部数值类型及 codec 记录；整数保留范围，浮点不支持范围。保留旧默认解析和聚合行为。

## [0.16.0] - 2026-11-02

- 新增 `#[miresidian::input("名称", batch)]` 参数级标记：普通业务方法可保持单个基础整数参数与单值逻辑，由生成包装层解析 `1|3|5`、`1-5` 等数组输入，按位置广播、顺序调用并聚合结果。
- `batch` 不适用于初始化、关闭、常驻探测或 Config 参数；未启用根 crate 的同名 feature 时，带标记的节点在编译期失败。

## [0.15.0] - 2026-10-30

- operation 支持 async 方法，生成 Send Future 业务桥和同步兼容桥；初始化、关闭和探测支持 async 生命周期桥。
- DLL 同步入口共享 OnceLock<NodeRuntime>，完整业务调用不再持有外层 Mutex。
- 配置、命名、默认值、编解码和返回文本契约保持；未新增 C ABI 入口。
- 验证包含宏编译诊断、原生 async 方法、默认/全特性与实际动态库加载。

## [0.14.0] - 2026-10-30

- instances 声明、构造预校验和节点契约生成；当前已发布版本。
- 此组件独立管理语义版本，只在实际变化时升版及单独发布；历史统一列车编号不构成联动要求。
